# 百度网盘申请与接入教程

更新：2026-10-04

## 当前版本能做什么

拾光图鉴采用“账号授权 + 服务端文件接口”。百度连接和加密凭证保存在网站账号中，同一账号在电脑、手机和平板登录后可继续使用。无需本机连接包；Codex/Gemini 的本机分析连接仍有各自的设备要求。

第一版是原图备份，保留现有云端原图、缩略图、标签、提示词和灵感集关系，不迁移或删除现有原图。可以自动备份新素材、备份现有素材、继续队列、重试失败、下载百度备份。备份不调用模型。一张图片加入多个灵感集不会重复备份。

网站尚未配置获批百度应用时显示“等待平台配置”。程序发布不代表百度申请已获批；普通访客不需要申请开发者应用，只需在管理员完成配置后授权自己的账户。

## 一、网站管理员申请

1. 打开百度网盘开放平台：https://yun.baidu.com/open/platform 。查看当前入驻与实名认证要求。官方 MCP 指引目前要求正式使用申请企业开发者，个人体验凭证不能用于正式发布；最新平台已合并升级，最终以平台审核为准。
2. 按平台要求准备真实的主体资料、联系人、应用名称、网站地址和用途说明。创建应用“拾光图鉴”，记录平台提供的 API Key / Client ID 和 Secret Key / Client Secret。
3. 申请文件上传、文件详情与下载、文件查询、用户信息、容量查询等权限。明确说明用途是用户授权自己的网盘进行私有素材备份，不是公开图床或共享一个账户给所有用户。
4. 确认应用允许的文件目录。程序需要 `/apps/实际应用目录`，不能自行假定显示名称就是目录名。第一版不申请或调用远端删除功能。
5. 将 OAuth 回调地址准确登记为：

   `https://character-atlas-wang-20261003.wqlwoaiwo.chatgpt.site/api/storage/baidu/callback`

   如平台要求回调安全域名，填写上述网站的域名；路径、HTTPS 和是否带尾部斜杠必须一致。自建版本替换为自己的正式域名。
6. 向百度确认收费、调用频率、普通用户/会员的传输条件，以及该业务用途是否获准。网盘会员不等于应用 API 权限，不能承诺免费或不限速。

可提交的用途说明：

> 本应用为用户提供私人图片素材管理。用户通过百度官方 OAuth 登录并授权自己的账户，应用将该用户的原图备份至获准应用目录，保存文件 ID 以支持本人下载。缩略图、标签及灵感集关系保存在本应用数据库。不同用户凭证与文件隔离，不提供公开图床，不向其他用户共享授权或原图下载地址。

## 二、安全配置与发布

由网站管理员在 Sites 的运行环境中配置以下项目，普通用户无需填写：

| 环境项 | 值 | 保密要求 |
| --- | --- | --- |
| BAIDU_CLIENT_ID | 获批应用的 API Key / Client ID | 运行环境配置 |
| BAIDU_CLIENT_SECRET | 获批应用的 Secret Key / Client Secret | 必须标为密钥 |
| BAIDU_SITE_ORIGIN | https://character-atlas-wang-20261003.wqlwoaiwo.chatgpt.site | 不带末尾斜杠 |
| BAIDU_APP_FOLDER | 平台确认的 /apps/实际应用目录 | 不带末尾斜杠 |
| AI_CONFIG_KEY | 网站现有的32字节 Base64加密密钥 | 保留现有值，禁止替换 |

不要把密钥提交到 GitHub、教程、前端文件或聊天。改变现有 AI_CONFIG_KEY 会影响密码验证和已有加密配置，不能为了接入百度重新生成它。

环境配置完成后重新发布网站，使新的配置生效。程序包含 Drizzle 数据库迁移，发布流程应应用新增的三张百度连接/授权请求/备份进度表。自建版本需执行等价的数据库迁移。

## 三、普通用户连接与跨设备使用

1. 登录自己的拾光图鉴账号，点击左侧“云盘连接”。
2. 点击“连接百度网盘”，在百度官方页面登录并授权。返回后显示“已连接”。网站不要求填写百度密码。
3. 点击“检测连接”，检查容量与授权。此检测证明账户与容量接口可用，上传和下载权限还需要实际文件测试。
4. 勾选“新上传素材自动备份到百度网盘”。此偏好也随账号同步，手机上传同样适用。
5. 点击“备份现有素材”处理历史图片；最近20条记录仅是显示数量，不限制队列总数。
6. 在另一台设备登录同一拾光图鉴账号，连接仍在。未完成任务可通过“继续备份”接着执行，已完成记录可“下载备份”。下载名称使用当前素材名。

授权快到期时服务端自动刷新。用户撤销授权、百度拒绝刷新、网站管理员改变应用或密钥失效时仍需重新连接；任何第三方连接都不能保证永久有效。

## 四、队列、命名与删除说明

原图通过预创建、4MiB分片上传、合并与文件信息核验完成备份。每个阶段保存进度并使用任务租约，防止两台设备同时传同一个分片。

网盘文件用稳定的素材内部 ID 命名，避免素材重名覆盖和编辑名称引发重复上传；从网站下载时使用当前素材名。不要手动修改应用目录里的文件。

上传成功后服务器在有限时间内继续备份；页面在线时继续处理队列。关闭所有页面后未完成任务会保留，下次登录可续传。本版本没有常驻离线任务调度，不承诺所有设备离线时持续跑完全部队列。连接保存与持续离线执行是两件不同的事。

重试一般保留已完成的分片。如百度上传任务过期，点击该失败记录的“重新备份”从原图重新上传。重新备份只覆盖本应用内该素材 ID 对应的备份文件，不改变网站素材；现有云端原图保留。

网站回收站不自动删除百度备份。清空网站回收站会移除对应网站备份记录，远端文件保留，可在百度网盘中自行管理。断开连接清除本网站的授权与备份记录，不删除远端文件；完全撤销授权还应在百度账号授权管理中解除关联。

## 五、上线验收

获批配置后，必须在实际账户验证：小图与超过4MiB的图片上传；分片中断续传；原图下载字节一致；使用素材名下载；重新登录及两台设备连接状态；授权刷新；两位用户数据隔离；容量不足；撤销授权；回收站及断开行为。

本次开发的自动化检查使用模拟百度接口，因为尚未取得获批应用，真实权限、百度网络可达性、速度和收费均未实测。不要在真实验收前开启“仅存网盘”或删除现有云端原图。
