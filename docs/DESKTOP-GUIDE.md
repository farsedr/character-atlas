# 拾光图鉴桌面版 1.0

Windows 10 / 11，64 位。使用安装版 `Character-Atlas-Setup-1.0.0.exe`，或双击免安装版 `Character-Atlas-Portable-1.0.0.exe`。不需要额外安装 Node.js。

界面、图片查看、集合、编号、标签、分页和上传操作沿用现有版本。首次打开在原有登录界面注册一个本地账号。账号、素材和原图保存在当前 Windows 用户的数据目录内，关闭软件或重新启动不会丢失。免安装版也使用该用户数据目录，不在临时解压目录保存素材。

本地账号与网站云端账号独立，原网站的数据保持原样，不会自动下载或迁移。打开本地素材不需要访问 chatgpt.site。模型 API、Codex、Gemini 调用仍需对应服务的网络和已登录账号。

软件内置本机连接服务，启动时自动配对；无需单独运行连接包。Codex / Gemini CLI 仍由用户安装和登录，可沿用“模型设置”中的指引。不会附带任何人的账号或 API 密钥。

按 Alt 显示原生菜单。可打开数据目录、备份素材库、刷新窗口、缩放界面和打开原云端网站。下载原图或 ZIP 会弹出 Windows 保存位置窗口。重复打开软件会聚焦已有窗口。

备份前等待上传、保存和分析完成。在“文件 → 备份本地素材库”选择目标目录，保存数据库、原图和 Windows 加密密钥。通过“文件 → 恢复本地备份”选择备份目录，校验通过后恢复；恢复前的素材库自动另存为副本，恢复后重新登录。该密钥只能由相同 Windows 账号解密，备份不是跨电脑云同步功能。

当前安装包未使用商业代码签名证书；Windows 可能显示未知发布者。尚未接入自动更新服务，新版本安装时保留用户数据，卸载也不主动清理素材。百度网盘需要独立获批的 OAuth 应用和回调，桌面本地库不复用网站的云端密钥。原有登录及云端功能说明沿用网站文字，以本说明中的本地保存规则为准。

开发：`npm ci`、`npm run build`、`npm run desktop`。打包：`npm run desktop:build`。验证：`npm run desktop:test`。
