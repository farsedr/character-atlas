# 拾光图鉴完整使用说明

网站：https://character-atlas-wang-20261003.wqlwoaiwo.chatgpt.site/

下载发布包：https://github.com/farsedr/character-atlas/releases/latest

## 注册、登录与同步

每位用户注册自己的项目账号。素材、标签、灵感集、模型配置和自定义 Skill 按账号隔离；同一账号跨设备登录同步自己的数据。注册时保存恢复代码，忘记密码使用恢复代码。当前邮箱只作为登录名，没有邮件找回；恢复后旧恢复代码与旧登录会话失效。账号安全可管理会话和修改密码。

Chrome / Edge 可安装网页应用；Android 用 Chrome，iPhone / iPad 用 Safari 添加到主屏幕。网页应用需要联网，分享启动包不是离线安装器。

## 上传、命名和自动分组

支持选择多张图片或文件夹，PNG / JPEG / WebP，单张不超过 20MB，文件夹中其他格式跳过。原图与预览分别保存，原上传名称保留在详情。

命名默认模型自动命名，也可保留原文件名称或逐张手动命名。自动命名需要视觉模型，失败时原图仍保留，可在详情重试。

分组默认模型自动分组：分析后按可见题材和主体生成灵感集名称，优先复用已有匹配灵感集，没有可靠依据时留在未分组。选择手动指定灵感集可保留自己的分类，后续分析不会覆盖。编辑时也可以切换分组方式。

自动命名或自动分组会启用上传后分析。纯手动上传可以选择手动命名、手动分组并取消自动分析。自动分组在模型分析成功后执行，不凭上传文件名猜测。

## 本机 Codex / 本机 Gemini

每位用户在自己的电脑安装 CLI，登录自己的账号，使用自己的额度；无需填写 API 密钥。通用连接包不包含账号、密码、配对码或固定电脑路径。

1. 安装 Node.js 22 或更新版本，完成后重新打开终端。连接包自动寻找安装路径；找不到环境时安装标准 Node.js。
2. Codex：运行 npm install -g @openai/codex，再运行 codex login，用自己的 ChatGPT 账号登录。
3. Gemini：运行 npm install -g @google/gemini-cli，再运行 gemini，选择 Login with Google。完成后退出 CLI。企业或学校账号要求以 Google 为准。
4. 下载 local-connector.zip 并完整解压。Windows 双击 start-codex.cmd；macOS / Linux 在解压目录运行 sh start.sh。
5. 保持连接程序运行，打开 http://127.0.0.1:4379/，复制本次连接码。在网站模型设置粘贴并连接，允许浏览器访问本地网络。
6. 选择本机 Codex 或本机 Gemini，查看安装与登录状态，选择模型和推理强度。上传或详情分析时也可以临时选择模型。下面的 API 字段是可选项。

默认 Codex GPT-6 Luna / low，Gemini Gemini 2.5 Flash Lite / default。模型实际可用性、额度和收费以自己的账号为准，不保证所有账号都有列出的模型。失败不会自动升级到更贵模型。Gemini 检测的是本地登录缓存，不保证网络或全部模型授权正常。

连接包版本 3 支持自动分组。每次重启会生成新连接码，需要重新配对；连接码仅保存在当前页面会话。换设备重新安装、登录、配对。手机不能直接连接另一台电脑的 localhost。

连接程序只监听本机回环地址。不要公开 4379 端口或分享连接码。修改网站域名时开发者需要同步修改连接程序允许的 Origin。

## 可选 API 配置

不用本机模型时，可以填写支持图片的模型 ID、HTTPS 服务地址和自己的 API 密钥。支持 OpenAI 兼容 Chat、Responses、Anthropic、Gemini 原生协议。费用由所选服务商收取。密钥在服务端按账号加密保存，不返回页面。本机模型不要求这些字段，也不会自动使用其他付费配置。

## 分析、标签与 Skill

详情按 12 个父标签分行展示：画风、题材、形态、材质、比例、气质、年龄、时代、性别、服饰、发型、妆容。同一行排列多个子标签。

内置 Skill 执行完整 24 维视觉分析，保存置信度、可见证据与不确定点。子标签可以由模型根据图片新增，也可手动修改，不要求只能从预设列表选择。证据不足时保留未知；年龄与性别分析视觉年龄和视觉呈现，不判断真实身份。额外的构图、镜头、光影等维度保存在分析结果中。

提示词未填写时自动生成中文提示词；已经填写的提示词与手动标签保留。可以在详情编辑。

模型设置 → 分析 Skill → 下载模板 → 修改独立 SKILL.md → 选择并安装。文件需要 YAML 前置信息中的 name 和 description，最多 24000 字符；外部引用文件不会一起安装。各账号独立保存，也可恢复内置规则。自定义 Skill 补充分析要求，固定输出结构、父类别和证据要求继续生效。

## 搜索、编辑和原图下载

支持搜索素材名、原文件名、描述、标签、提示词。筛选默认收起部分维度，展开可使用全部 12 个。可以筛选灵感集和选择排序。空灵感集自动清理。

下载原图和批量 ZIP 中的文件均以当前素材名命名，添加原图格式对应的 .png / .jpg / .webp 扩展名。修改素材名后，下次下载使用新名称；原上传名称只保留在详情。

文件名中的路径分隔符和不允许字符替换为下划线；ZIP 同名文件加 (2)、(3) 等序号，避免覆盖。下载保持原图字节，不重新压缩图片。每批最多 200 张，更多选择分成多个 ZIP。

## 回收站

删除素材后进入回收站。支持恢复单张、永久删除选中、清空。永久删除需要界面确认，成功后无法恢复；恢复保留文件和信息。编号可重用，内部文件标识不重用。

## 云端存储与容量

生产使用 Sites 绑定的 D1 保存账号与元数据，R2 保存原图和预览；数据不存储在 GitHub 仓库。发布包不包含用户云端图片。

每账号显示编号 CHAR-00001 至 CHAR-99999 是编号上限，不是存储容量承诺；删除释放编号。单张 20MB 是应用上传限制。总容量、流量与费用取决于部署平台账户和配额，需在平台管理页面查询，不能据此宣称无限存储。原图、预览与回收站文件都占空间，永久删除移除两份对象。

## 排错

找不到 Node 或 CLI：完成安装后重开终端，确保装在当前用户的 PATH 中。
端口占用或旧版本：关闭旧连接程序再启动版本 3。
配对失败：检查连接程序仍运行、连接码来自本次启动、浏览器允许本地网络、访问正式网站地址。
模型失败：重新登录自己的 CLI，检查账号模型授权、额度和网络，不会自动切换更贵模型。
分析失败：原图保留，修改配置后在详情重试，不会凭空生成分组或标签。

## 开发与部署

源码 ZIP 解压后安装 Node.js 24+，运行：

    npm ci
    npm run build
    npm test
    npm run preview

本地预览使用模拟数据库/对象存储，与生产隔离，不用于保存正式素材。生产输出 dist/server/index.js，兼容 Cloudflare Workers，使用 Sites 部署。DB / BUCKET 分别绑定 D1 / R2，应用 drizzle 中全部 SQL 迁移（0000–0003）。当前 .openai/hosting.json 指向本项目，新部署需要注册自己的站点和绑定。

AI_CONFIG_KEY 是 32 字节 base64 部署秘密，用于模型密钥加密和密码 pepper；禁止放入源码、分享包或公开仓库，不能随意替换，轮换需要专门迁移。

生成通用连接包：

    node scripts/package-connector.mjs

生成 GitHub 发布文件：

    node scripts/package-release.mjs

release/ 被 Git 忽略。源码包和连接包不包含实际 .env、数据库备份、用户原图、CLI 登录文件、会话凭据或配对码。
