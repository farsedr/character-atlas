# 素材图库
独立账号的云端图片管理应用。每个用户自行注册，使用同一账号在不同设备登录后同步自己的素材、标签、项目和模型配置。不存在管理员邀请、子账号或共享账号库。

## 使用
打开部署地址，注册账号并保存一次性显示的恢复代码。邮箱目前仅作为登录名称，未做邮件验证，不支持邮件找回。忘记密码使用恢复代码，恢复后旧代码失效且所有旧会话撤销。
Windows/macOS/Linux 可在 Chrome/Edge 中安装应用；Android 使用 Chrome 安装；iOS/iPadOS 使用 Safari 添加到主屏幕。需要联网。分享包位于 public/share/素材图库分享包.zip，包含各平台启动入口与说明，不包含服务端源码、密钥、数据库或用户素材。它是云端应用的分享包，不是离线 EXE/MSI/DMG 安装器。前端压缩无 source map；前端执行代码仍可被检查，无法绝对防逆向。

## 功能
- 素材总览、全文搜索、十类标签筛选、项目筛选和分页。
- 图片与文件夹上传；PNG/JPEG/WebP 原图保存至 R2，原始尺寸由服务端读取文件头。
- 原文件名、逐张自定义、模型提取的1至4个汉字三种命名方式。自动命名失败时保留原文件名并允许重试。
- 源文件大小、分辨率与实际像素、最简整数比例、上传时间，手动编辑生图提示词。
- 自定义项目。固定父类别：画风、题材、形态、材质、比例、气质、年龄、时代、性别、服饰。用户和模型均可新增子标签与分组，父类别没有编辑删除接口。
- 服饰预设六组40项，包含传统国风、职业制服、亚文化、幻想、日常场合和特殊款式。
- 批量删除到回收站；恢复保留文件和信息并分配新的可用编号。
- 每账号 CHAR-00001 至 CHAR-99999，原子SQL分配最小未使用编号；删除释放编号。内部对象标识不复用，旧页面不会指向新文件。
- 用户自备模型密钥：OpenAI兼容Chat、Responses、Anthropic、Gemini，含主流视觉服务商预设和自定义HTTPS接口。模型图片调用可能产生服务商费用。手动管理无需模型配置。

## 账号与安全
密码长度12–128，独立随机盐，服务端 HMAC pepper + PBKDF2-SHA256 100000轮（Worker单次迭代上限），不保存明文密码。pepper从部署加密主密钥取得，数据库单独泄露不提供离线验证密码的材料。
会话令牌32字节随机，仅存SHA256摘要；浏览器使用 __Host- HttpOnly/Secure/SameSite=Lax Cookie，14天到期，不用localStorage存凭据。
变更接口验证同源 Origin。登录、注册、恢复及密码修改使用数据库原子限流（按IP和账号，每15分钟20次），可撤销单个或所有其他设备会话。
素材、下载、回收站、标签、项目和模型配置均在服务端按账号隔离。模型密钥 AES-GCM 加密，并绑定账号作为AAD；不返回密钥。服务地址只接受公网HTTPS，拒绝显式内网IP及所有重定向。
尚未接入邮箱验证、邮件找回、MFA或正式安全审计；需要进一步上线运维时应接入可靠邮件服务、监控和恢复演练。

## 数据与迁移
D1用于账号、会话、元数据，R2用于原图和预览。Drizzle schema位于db/schema.ts；已应用迁移0000/0001保持不变，0002增量扩展。
旧实际素材与标签归属原站点所有者账号（仅信任Sites透传身份进行首次关联），新用户不能领取旧库。旧内部ID和R2对象键不更改，公开ID按创建顺序补齐。删除不重排其他素材编号。6张旧演示卡片已移除，不影响R2中真实上传文件。
原站点外层访问策略不会因应用登录而自动改变。邀请其他独立用户使用时，应由所有者明确将网站入口改为公开；入口公开不公开账号数据，全部素材API仍需应用会话。
AI_CONFIG_KEY 必须是32字节base64部署秘密，禁止放入代码或分享包，也不能随意轮换（否则模型密钥无法解密，密码pepper变更需迁移）。

npm run preview
