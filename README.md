# 角色图谱

AI角色分类项目库雏形，包含7个分类维度、104个词条、6份示例角色档案、3个示例项目。

## 当前能力
- 关键词与多维组合筛选、排序、角色详情
- 分类词条浏览与项目分组
- 响应式界面和键盘操作

## 数据维护
`dist/data.js` 是当前单一数据源。角色使用稳定的 AST-CHAR-* 标识，项目使用 PRJ-* 标识。修改角色名称不修改标识；重要设定更改递增 version。classification 中的值必须存在于 taxonomy 对应维度；projectId 必须引用 projects 中的项目。

这是可浏览的静态雏形，未实现新增编辑、文件上传、多人协作和云端数据库。当前概念与图片全部为示例，不代表正式资产。后续可接入角色状态版本、素材引用、提示词版本、生成记录和审核记录，避免将分类标签与生产状态混用。

## 本地预览
在 dist 目录运行任意静态 HTTP 服务，打开根页面。直接打开 dist/index.html 也可浏览。无需构建或安装依赖。
