# 视觉判定标准 1.1.0

## 根据主体分配观察重点
- 人物、拟人角色：观察服饰结构、发型妆容、可见姿态与人物所在空间；不可见人体部位不补全。
- 风景、建筑：观察空间结构、前中后景、建筑形态、自然元素、材质与光色。无人画面的年龄、性别呈现、发型、妆容等通常为 not_applicable。
- 产品、器物：观察形体、结构、材质表面、连接关系、使用状态与展示方式；不猜品牌、型号、材料化学成分或尺寸。
- 动物、非人主体：依据实际可见结构描述，不强行套用人物服饰、妆容与年龄体系。
- 混合或多人画面：先选视觉主主体，在 primary_subject 明确；secondary_subjects 记录次要主体。同一维有不同主体特征时，证据标明区域或主体，不把多个人的发型、服装拼成一个人。
- 模糊、远景、遮挡：区分不适用与无法确认；只降低相关维度的确定性，不否定整张图片。

## 24维边界
| ID | 判断内容与边界 |
|---|---|
| style | 表现媒介、写实程度、视觉流派；题材不等于画风，不推断制作软件。 |
| subject | 画面主题、世界背景和角色视觉类型；服装或表情不能单独证明职业或身份。 |
| form | 主体可见结构、形态及非人特征；不要把景别当作形态。 |
| material | 纹理、反射、透明度、粗糙程度及材质视觉表现；不确定成分时用“金属质感”等。 |
| proportion | 可见造型比例和风格化程度；不是图片长宽比，不编造精确头身数。 |
| vibe | 整体视觉气质；不推断真实人格，不重复表情与天气。 |
| visual_age | 外观年龄段；遮挡或风格化过强用 unknown，不推断真实年龄。 |
| era | 装束、建筑和器物支持的时代视觉风格；不足时不指定朝代或年份。 |
| gender_presentation | 外观的性别化视觉呈现；不能推断真实性别或认同。 |
| clothing | 可见类型、版型、领袖、层次、装饰及配饰；按区域明确归属，不补画外衣物。 |
| composition | 主体位置、视觉中心、留白、遮挡、对称与画面组织。 |
| shot_scale | 主体在画面中的覆盖范围；单选，不等同真实距离。 |
| view_angle | 俯仰与观察方向；方向不明时用相对画面位置。 |
| lens_language | 透视、景深、虚化、压缩等可见效果；不猜焦距、光圈或镜头型号。 |
| lighting | 光向、软硬、冷暖、轮廓和作用区域；不凭空添加多层光源。 |
| color | 主色、明度、饱和度和配色关系；dominant_colors 用可见颜色名称，不猜精确色值。 |
| scene | 可见地点和空间结构；不把气氛、世界观或身份当地点。 |
| atmosphere | 天气、雾气、空气感及环境视觉氛围；与人物气质区分。 |
| pose | 身体朝向、关节、重心和肢体关系；遮挡部位不猜测，方向不明时描述画面左/右。 |
| action | 可见的动作或交互；静态姿态不能证明动作过程与行为意图。 |
| expression | 可见的眉眼、嘴角等表情表现；不推断内心或真实情绪。 |
| hairstyle | 发色、长度、分区、卷直、编扎与可见头饰；不把头饰材质当发色。 |
| makeup | 可见妆面、眉眼、唇色和装饰；自然面貌与图像调色不能直接当作化妆。 |
| effects | 明确的光束、能量、粒子、散景等视觉效果；不将普通反射全部解释为特效。 |

## 标签取舍与一致性
同义词优先采用词表中的规范表达；不要堆砌宽窄重复或近义标签。同一画面不同区域支持的差异可以共存，但证据必须注明位置。真正互斥的判断保留证据更强者，不足以区分则用较宽表述或 unknown。

先观察再命名。仙侠装束和光环可支持幻想角色类型，但不是实际身份的证明；仅暗色背景不能推出魔女，仅清冷表情不能推出师尊。信息量少的图片使用简洁描述，不为满足长度编造元素。

输出前检查：主体一致、每个保留标签有对应证据、未知项诚实、维度上限正确、名称分组规则正确、JSON完整。格式修复只调整类型与空值，不通过编造可见内容满足校验。
