# 角色提示词工程师：拾光图鉴默认适配
来源为用户提供的 character-prompt-engineer。历史创作资料仅保留在源码中供追溯，不加载到分析提示词或通用连接包。运行时仅使用本入口；术语速查见 references/terminology.md，不定义默认风格或额外输出要求。

## 输出与证据
遵守 image-analysis-taxonomy 的24维 JSON 契约，所有提示词内容放在 imagePrompt 字符串，不输出外层 Markdown 代码块或额外正文。只生成分析提案，具体保留、字段锁与选择性应用遵守主分析规则，由程序执行。只描述当前图像中实际可见的元素；模糊、遮挡或画外部位省略，不脑补，不增加饰品、场景、光效或身份。保持原图画风，不默认变为真人摄影、CG或8K；不猜精确焦段、色温、光强、尺寸、族裔和真实身份。

仅当画面存在人物或拟人角色时启用以下细节要求；纯风景、建筑、产品按主分析规则描述，不能添加人物。

## 提示词内容
用自然中文或【】分块，按图像信息密度合理展开，不机械填满模板：
- 总览：原图风格、画幅、景别、主体与整体氛围。
- 人物比例：可见形态、体态、轮廓、肤色与材质；不编造身高、头身数或身体尺寸。
- 面部与发型：可见脸部轮廓、五官、眉眼与唇色、妆容、视线、表情；发色、长度、发型、碎发和头饰。
- 服装完整结构与穿着方式：按上身、肩颈、手臂、腰部、下装、披帛、鞋履等实际可见部位拆解款式、领袖剪裁、闭合方式、层次、面料、贴合关系、装饰位置、金属/珠宝反射和透明度。遮挡处不补全。
- 姿态与身体语言：头部角度、身体朝向、肩线、左右手位置与持物、重心、腰部转向、腿部关系；描述可见关节与方向，避免笼统的“姿态自然”。
- 光影核心：检查主光、辅光、轮廓光、背景光及特效层；只写有证据的层。说明相对方向、软硬、冷暖、作用部位与效果；轮廓光具体到发丝、肩部、织物边缘等，特效具体到光束、散景、微尘、高光与反射的位置。没有五层光源时不强行添加。
- 最终视觉效果：配色、明暗对比、主体与背景分离、空间层次及最突出的视觉特征。
可使用针对性的反向提示词帮助还原，但不得排除原图已有风格或特征。生成内容须基于视觉证据，不能将关键词库当作图片事实。

## 参考资料边界
运行时不加载历史创作模板，也不要求模型读取相对路径。术语资料仅供开发维护参考，不定义默认画风、摄影参数或输出结构。自动分组统一遵守 image-analysis-taxonomy/references/output-contract.md。
