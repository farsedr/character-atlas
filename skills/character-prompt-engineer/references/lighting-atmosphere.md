# 光影特效精细化描述方法论

## 核心原则：光源分层 + 区域定位

高级感来自多光源混合，而非单一光。描述时必须回答三个问题：
1. **有几层光**（主光/辅光/轮廓光/背景光/特效光）
2. **每层光的参数**（位置、角度、性质、色温、强度）
3. **作用在哪个具体区域**（人物哪个部位/服装哪块材质/背景哪个空间）

---

## 一、五层光源体系

任何高级画面都可拆解为以下五层光源，逐层描述：

### 第1层：主光（Key Light）—— 塑造主体形态

**必须描述的参数：**
- **位置**：正前方/左前45°/右前45°/正侧90°/侧后方
- **高度**：平角/俯角30°/仰角
- **性质**：硬光（阴影锐利）/柔光（阴影过渡）/聚光（范围集中）
- **色温**：暖金3200K/中性5500K/冷蓝7000K
- **强度**：主导画面/中等/微弱
- **作用区域**：面部哪块骨骼（额头/鼻梁/颧骨/下颌）、身体哪侧、服装哪块

**示例：**
```
主光从左前方45°俯角30°打入，柔光箱漫射性质，暖金色温4000K，主导画面亮度，照亮左侧面部（额头、左颧骨、鼻梁左侧）与左肩胸衣，在右脸形成自然过渡阴影
```

### 第2层：辅光（Fill Light）—— 控制暗部层次

**必须描述的参数：**
- **位置**：主光对侧/正前方低位
- **强度**：主光的1/2 / 1/3 / 1/4（光比）
- **性质**：极柔（反光板/柔光布）
- **色温**：与主光同色/对比色（暖主光+冷辅光=电影感）
- **作用**：提亮暗部细节/降低对比度/保留阴影区纹理

**示例：**
```
辅光从右前方低位打入，白色反光板反射，强度约为主光1/3，冷白色温6500K，与暖金主光形成色温对比，提亮右脸暗部与胸衣阴影区，保留皮肤与面料纹理不死黑
```

### 第3层：轮廓光/边缘光（Rim / Edge Light）—— 分离主体与背景

**必须描述的参数：**
- **位置**：正后方/左后/右后/侧后高位
- **性质**：硬光（形成锐利亮边）/聚光
- **色温**：金色（暖边）/白色（冷边）/彩色（氛围边）
- **强度**：强（过曝亮边）/中（清晰轮廓）/弱（微妙分离）
- **精确作用部位**：必须列出具体落在哪些边缘

**轮廓光常见落点（必须精确列举）：**
- 头发：发丝边缘、发顶、飘动碎发、发饰金属
- 面部：下颌线、鼻梁侧面、耳廓、肩颈连线
- 肩部：肩峰轮廓、锁骨边缘、露肩区域皮肤
- 服装：领口边缘、薄纱袖边缘、披帛飘带、裙摆外轮廓
- 身体：手臂外侧、腿部开叉边缘、背部脊柱线

**示例：**
```
轮廓光从正后方高位打入，硬光聚光性质，暖金色温，强度偏高形成过曝亮边，精确落在：发丝边缘（每根碎发通透发光）、肩峰与锁骨连线、露肩皮肤轮廓、薄纱披帛边缘、裙摆外层飘片，将人物从深色背景中分离出来
```

### 第4层：背景光（Background Light）—— 塑造空间深度

**必须描述的参数：**
- **位置**：背景后方/侧后方/顶部
- **形式**：聚光光束/均匀洗墙/渐变光
- **色温**：与主体统一/对比
- **作用**：照亮背景/产生光束/营造纵深

**示例：**
```
背景光从左后上方斜向打入，聚光性质形成可见光束（丁达尔效应），暖金色温，光束从左上斜穿画面至右下，穿过人物肩侧，在背景中形成由亮到暗的渐变纵深
```

### 第5层：特效光（Special Effects）—— 提升高级感与氛围

**常见特效类型与精确描述：**

| 特效 | 描述要素 | 空间位置 |
|------|---------|---------|
| **丁达尔光束** | 光源方向、光束数量、角度、颜色、可见度 | 背景空间，穿过人物哪个部位 |
| **散景/Bokeh** | 光斑大小、颜色、密度、分布区域 | 背景中景/远景，前景虚化 |
| **空气颗粒/微尘** | 颗粒大小、密度、是否被光束照亮 | 光束路径中/整个空气层 |
| **光晕/辉光** | 发光源位置、溢出范围、颜色 | 强光区域边缘 |
| **材质自发光** | 发光部位、颜色、强度、是否溢出 | 服装/武器/宝石/皮肤 |
| **反射光** | 反射源、反射方向、落在何处 | 地面/水面/金属/皮肤高光点 |
| **体积光** | 光的体积感、浓度、颜色 | 整个空间/特定区域 |

**示例：**
```
特效层：丁达尔光束沿背景光路径分布，光束中漂浮细密微尘颗粒被照亮；背景中景散布暖金色圆形散景光斑，大小不一密度中等；左下角披帛区域强光溢出形成柔和光晕；胸衣宝石与金属护甲片产生点状高光反射；地面有微弱暖光反射向上照亮裙摆下缘
```

## 二、人物各部位光影落点精确描述

描述人物光影时，必须精确到具体部位，不能笼统说"面部有光"。

### 面部光影分区
```
- 额头：主光照亮区域/高光点位置
- 眉骨：阴影线/高光边缘
- 眼窝：阴影深度/是否有补光
- 鼻梁：主光高光带/侧面轮廓光
- 颧骨：主光最亮区/腮红区域
- 鼻翼：阴影/高光
- 嘴唇：上唇高光/下唇阴影/唇面反光
- 下颌：轮廓光亮边/阴影过渡
- 耳廓：轮廓光通透/耳饰反光
```

### 肩颈胸光影分区
```
- 锁骨：轮廓光亮边/主光高光
- 肩峰：轮廓光最强点/主光过渡
- 颈前：阴影区/辅光提亮
- 颈侧：轮廓光/主光
- 胸口：主光区域/阴影纵深/皮肤高光
- 胸衣面料：主光质感呈现/阴影区纹理
```

### 手臂手部光影
```
- 上臂：轮廓光外侧/主光内侧
- 前臂：光影过渡/饰品反光
- 手背：主光/指节阴影
- 手指：轮廓光边缘/戒指高光
```

### 腿部光影
```
- 大腿：开叉处轮廓光/主光
- 膝盖：高光点/阴影
- 小腿：光影过渡/袜材质感
- 脚踝：阴影/鞋履反光
```

## 三、服装材质与光的交互（必须描述）

不同材质在光下产生完全不同的效果，描述时必须说明"什么光打在什么材质上产生什么效果"。

| 材质 | 主光下效果 | 轮廓光下效果 | 阴影区表现 | 高光特征 |
|------|-----------|------------|-----------|---------|
| **缎面** | 柔和大面积光泽，随曲面流动 | 边缘形成亮带 | 颜色加深但有反光 | 条状高光，随褶皱变化 |
| **薄纱/透纱** | 半透可见内层，颜色变浅 | 边缘过曝发光，纱质通透 | 几乎无阴影，透光 | 整体柔光，无明确高光点 |
| **蕾丝** | 镂空处透光，花纹清晰 | 边缘细碎亮边 | 镂空处透背景色 | 点状/线状高光沿花纹 |
| **粗麻/土布** | 哑光，织纹清晰 | 边缘纤维感亮边 | 深色死区，纹理可见 | 无明显高光，漫反射 |
| **金属/护甲** | 冷冽反光，雕花明暗 | 边缘锐利高光 | 深色凹陷 | 点状/面状高光，反射周围 |
| **皮革** | 半哑光，柔和反光 | 边缘亮带 | 深色有质感 | 柔和高光，随曲面 |
| **牛仔** | 哑光，斜纹可见 | 边缘磨损处亮 | 深蓝色阴影 | 无高光，漫反射 |
| **针织** | 哑光，坑条纹理 | 边缘柔软亮边 | 纹理深处阴影 | 无高光，漫反射 |
| **宝石/水钻** | 折射彩色光斑 | 边缘火彩 | 深色内部 | 强点状高光，色散 |
| **珍珠** | 柔和晕彩 | 环形高光 | 柔和阴影 | 中心高光+晕彩 |
| **皮肤（带珠光）** | 细腻光泽，毛孔可见 | 边缘通透金边 | 暖色过渡 | 颧骨/鼻梁/肩峰高光点 |

**材质光影描述模板：**
```
[主光]打在[材质]上，呈现[效果]；[轮廓光]在[材质]边缘形成[效果]；阴影区[表现]；高光特征为[描述]
```

**示例：**
```
主光打在粉金缎面胸衣上，呈现柔和流动光泽随胸衣曲面变化；轮廓光在缎面领口边缘形成亮带；阴影区颜色加深但仍有反光保留刺绣纹理；高光为条状随褶皱分布。薄纱披帛在轮廓光下整体过曝发光，纱质通透可见内层，几乎无阴影。金属护甲片在主光下产生冷冽点状高光反射，雕花凹陷处为深色阴影。
```

## 四、高级感光影组合模板（精确到每层参数）

```

【整体】暖金主调，明暗对比强（亮部过曝+暗部有细节），人物与背景分离清晰，空间纵深强
```


### 模板3：夕阳逆光森系

```
【主光】右前方低位（夕阳角度），暖金3200K，硬光性质，强度高，照亮右脸与右肩，形成温暖金色肤色
```

## 五、光影描述质量检查（输出前必查）

- [ ] 是否描述了至少3层光源（主光+辅光+轮廓光）
- [ ] 每层光是否有：位置+角度+性质+色温+强度
- [ ] 轮廓光是否精确列举了落在哪些具体部位
- [ ] 是否描述了背景光/空间光
- [ ] 是否有特效层（丁达尔/散景/颗粒/光晕/反射）
- [ ] 特效是否说明了空间位置（哪里有什么）
- [ ] 每种服装材质是否描述了光下效果
- [ ] 人物关键部位（面部/肩颈/胸/手/腿）是否有光影落点
- [ ] 整体色调与明暗对比是否明确
- [ ] 是否避免了笼统表述（如"光线柔和"→ 替换为具体参数）

## 六、常见笼统表述 → 精细化替换

| 笼统表述（禁用） | 精细化替换（推荐） |
|-----------------|-------------------|
| "光线柔和" | 左前方45°柔光箱漫射，暖金4000K，照亮左脸与左肩 |
| "逆光效果" | 正后方高位聚光，暖金3500K，在发丝、肩线、薄纱边缘形成过曝金边 |
| "有氛围感" | 背景中景散布暖金散景光斑，光束中漂浮微尘颗粒，左下角有光晕溢出 |
| "皮肤有光泽" | 颧骨、鼻梁、肩峰有自然高光点，皮肤带细腻珠光在主光下呈现通透质感 |
| "衣服有质感" | 缎面在主光下呈现流动条状光泽，阴影区有柔和反光保留刺绣纹理 |
| "背景虚化" | 背景中景暖金色圆形散景光斑，大小不一密度中等，远景渐变为深灰 |
| "光影对比强" | 亮部（发丝/肩线/薄纱）过曝，暗部（脸侧/腰腹阴影）有纹理不死黑，光比约4:1 |
| "丁达尔效应" | 左后上方聚光形成2道斜向金色光束从左上穿至右下，光束中微尘被照亮可见 |
