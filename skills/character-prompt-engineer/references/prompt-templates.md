# 提示词结构模板与风格速查

## 一、标准输出结构

每次输出必须包含以下三个部分，顺序固定：

### 第一部分：正向核心提示词（代码块）
```
[画质与风格前缀] + [构图] + [人物设定] + [服装装备] + [姿态] + [场景背景] + [光线氛围]
```

### 第二部分：反向提示词（代码块）
```
[风格排除] + [人物排除] + [服装排除] + [光影排除] + [质量排除]
```

### 第三部分：关键细节解析（正文）
分点解析设计逻辑，3-5点，每点有标题+解释

---

## 二、正向提示词万能公式

```
[画质]，[渲染风格]，[构图景别]，[光线]，[背景]，[人物：年龄/人种/身形/气质/面部/发型]，[服装：按五维拆解]，[配饰武器]，[姿态动作]，[氛围关键词]，[材质强调]
```

### 画质前缀（按风格选择）
- **写实摄影**：8K超高清，极致写实人像摄影，照片级真实，细腻皮肤肌理
- **游戏CG**：8K超高清，游戏原画质感，电影级3D渲染，UE5实时渲染
- **概念插画**：8K超高清，电影级概念艺术，数字绘画，细腻笔触
- **设定板**：8K超高清，角色设定集，纯白背景，均匀漫射光，专业排版

### 构图景别
- 全身立绘（full body）
- 半身近景（half body / bust shot）
- 面部特写（close-up / portrait）
- 三视图排版（three-view layout）
- 设定板排版（character sheet layout）

---

## 三、反向提示词万能公式

```
卡通/动漫/Q版/手绘/低清/模糊/五官畸形/肢体失调，[不符合的服装]，[不符合的人物状态]，[不符合的光影]，[质量问题]
```

### 反向词库（按需组合）
**风格排除**：卡通，动漫，Q版，手绘平涂，厚涂笔触，3D建模感，CG感过重
**人物排除**：五官畸形，多余肢体，比例失调，笑容，甜妹神态，浓妆艳抹，短发（如指定长发），眼镜，帽子
**服装排除**：（根据正向服装写反义，如正向是古装则写"现代装/西装/休闲装"）
**光影排除**：强光过曝，暗黑死黑，正面平光（如指定逆光），无轮廓光，无散景
**质量排除**：低分辨率，模糊，塑料感，磨皮过度，面料无纹理，背景杂乱

## 四、各风格核心要素速查

### 1. 古风汉服/唐风/宋制
**核心要素**：形制（齐胸/齐腰/对襟/大袖衫）、披帛、发髻、发簪/步摇/花钿、汉服妆造
**面料**：纱、缎、绫、罗、刺绣、织金
**氛围**：温婉、华贵、清雅、灵动、仙气
**光影**：柔光、古风场景、灯笼/烛光/自然光

### 2. 仙侠/奇幻角色
**核心要素**：非人类特征（精灵耳/角/翅膀/尾巴）、能量光效、法器/武器、华丽头饰、披帛飘带
**面料**：透纱、发光材质、金属护甲、宝石镶嵌
**氛围**：绝尘、清冷、魅惑、神圣、魔幻
**光影**：逆光、丁达尔光束、能量发光、粒子特效

### 3. 西装/商务/精英
**核心要素**：西装版型（修身/宽松）、衬衫、领带/领结、袖扣、手表、皮鞋
**面料**：羊毛哑光、缎面领带、漆面皮鞋、金属表带
**氛围**：干练、威严、冷峻、专业、精英
**光影**：影棚侧光、浅灰背景、柔和明暗

### 4. 婚纱/礼服
**核心要素**：版型（鱼尾/A字/蓬裙/抹胸/深V）、头纱、皇冠、手套、蕾丝、钉珠
**面料**：缎面、蕾丝、薄纱、水钻、珍珠
**氛围**：庄重、浪漫、华丽、高级、梦幻
**光影**：窗边柔光、宫廷场景、暖金色调

### 5. 街拍/日常休闲
**核心要素**：穿搭组合（上衣+下装+鞋+包）、品牌感、松弛姿态、场景感
**面料**：牛仔、针织、帆布、棉麻
**氛围**：随性、自然、生活感、时尚、街头
**光影**：阴天漫射光、街景虚化、冷灰/暖调

### 6. 影视定妆/年代戏
**核心要素**：时代特征服装、做旧质感、符合年代的妆发、身份符号（配饰/道具）
**面料**：粗麻、土布、做旧缎、磨损皮革
**氛围**：真实、质朴、年代感、戏剧感
**光影**：影棚均匀光、纯灰背景、写实质感

### 7. 医疗/职业制服
**核心要素**：制服形制、职业标识、医用耗材（如适用）、专业状态
**面料**：医用棉质、制服面料、一次性耗材
**氛围**：专业、真实、临床感
**光影**：无影灯/均匀柔光、纯白背景

## 五、人物设定结构化模板

当需要输出人物小传时，按以下结构：

```
【姓名】：
【年龄】：
【人种】：（东亚/白人/黑人/混血）
【身形】：（身高/体型/比例，如"九头身，腿长占2/3，D罩杯"）
【气质】：（3-5个关键词）
【面部】：（脸型/眼型/瞳色/眉型/唇色/皮肤/妆容/气质神态）
【发型】：（颜色/长度/造型/发质）
【服装】：（按服装五维拆解）
【配饰】：（首饰/武器/道具）
【性格】：（核心性格+反差）
【背景】：（身份/职业/故事）
```

## 六、用户偏好适配（基于历史交互）

当用户表现出以下偏好时，主动适配：

| 用户信号 | 适配动作 |
|---------|---------|
| "出提示词" / 上传图片无文字 | 反推参考图提示词，三部分结构输出 |
| "太繁琐了" / "饰品太多" | 精简配饰，强调素雅克制 |
| "改成XX朝代/XX风格" | 替换服装形制与时代元素，保留其他 |
| "性感一点" / "能看见XX" | 使用服装细节指南的安全表述，增加露肤结构描述 |
| "规避敏感词" / "检测" | 启用敏感词映射表，全部替换为专业术语 |
| "三视图" / "设定板" | 使用设定板排版规范，纯白背景+均匀光 |
| "详细描述服装" | 启用服装五维拆解法，逐维度详细描述 |
| "专业角色设计师" | 输出前声明身份，使用行业术语，增加设计逻辑解析 |
| "不要XX" | 强否定指令必须写入反向提示词，并在正向中明确规避 |
| 指定画幅（9:16/16:9） | 在提示词开头明确画幅比例 |
| 指定人种/年龄/身材 | 严格遵循参数，在人物设定中明确写出 |

## 七、输出质量自检清单

输出前逐项核对：
- [ ] 正向提示词包含：画质+风格+构图+人物+服装+姿态+光影+氛围
- [ ] 服装描述覆盖五维（款式/面料/装饰/身体效果/最终效果）
- [ ] 反向提示词针对性强（不是通用模板，而是针对本次内容）
- [ ] 细节解析有设计逻辑（不是重复提示词，而是解释"为什么这样设计"）
- [ ] 无敏感词（如涉及大胆穿法，已使用安全表述）
- [ ] 用户的强否定指令已落实
- [ ] 用户指定的参数（比例/画幅/人种/风格）已遵循
- [ ] 代码块格式正确（正向/反向分别用代码块包裹）
