# 角色设定板（Character Sheet）排版规范

## 一、标准设定板结构

### 完整版（游戏/影视级）
```
┌─────────────────────────────────────────────────┐
│  顶部：6视角全身立绘（正/34左/左/背/34右/右）    │
├──────────────────┬──────────────────────────────┤
│  动态战斗姿态    │  面部大特写  │  标准全身立绘  │
├──────────────────┴──────────────────────────────┤
│  细节拆解行：脸/眼/唇/额饰/耳饰/手/足/发型多角度 │
├─────────────────────────────────────────────────┤
│  服装拆解行：胸甲/腰甲/肩袖/裙摆/背部/武器独立   │
├─────────────────────────────────────────────────┤
│  底部：材质色卡 + 纹饰参考 + 锁定设定图           │
└─────────────────────────────────────────────────┘
```

### 精简版（服装/定妆级）
```
┌──────────────────────────┬───────────────────┐
│  左侧：三视图全身立绘      │  右上：面部正面特写 │
│  （正面/侧面/背面）        │  右下：面部侧面特写 │
└──────────────────────────┴───────────────────┘
```

### 单图版（海报/概念级）
- 单人大画幅，动态姿态，强光影，背景有氛围
- 不需要多视角，追求单张视觉冲击力

## 二、各区域内容规范

### 区域1：多视角全身立绘
**必须包含的视角**：
- 正面（Front View）：标准站姿，双臂自然垂于体侧，正视镜头
- 纯侧面（Side View）：90°侧身，头部平视，展示侧面轮廓
- 背面（Back View）：背对镜头，展示后背结构、发型背面、服装后背
- 3/4侧面（3/4 View）：45°角，可选左右各一

**姿态要求**：
- 所有视角使用同一角色、同一服装、同一比例
- 站姿统一（立正/双手插兜/自然垂手），避免动态差异
- 各视图等距排列，大小一致

### 区域2：面部特写
**必须包含的角度**：
- 正面特写：胸部以上，正视镜头，展示妆容、五官、头饰正面
- 侧面/3/4侧面特写：展示鼻梁轮廓、下颌线、发型侧面

**细节要求**：
- 妆容清晰可见（眼妆、唇色、腮红、皮肤纹理）
- 头饰/额饰/耳饰完整展示
- 发型细节（刘海、碎发、发髻结构）

### 区域3：细节拆解
**面部拆解**（按需选择）：
- 全脸、眼睛特写、嘴唇特写、眉毛、耳朵
- 额饰/花钿、耳饰、面纹/纹身/伤疤

**身体部件**：
- 双手（手背+手心）、双足（穿鞋/赤脚）
- 发型多角度（正面/侧面/背面）
- 特殊身体特征（精灵耳、尾巴、翅膀、角）

### 区域4：服装拆解
**上装**：
- 胸甲/领口、腰封/腰带、肩甲/袖型、背部结构
- 面料特写、刺绣/纹样特写、金属配件特写

**下装**：
- 裙型/裤型、裙摆细节、开叉结构、腿部饰品

**武器/道具**：
- 独立展示，正面+侧面，标注材质与细节

### 区域5：材质色卡与参考
**色卡**：
- 排列5-8个主色块，标注用途（皮肤/发色/主服装/辅色/金属/宝石）
- 每个色块可附材质说明（哑光/光泽/通透/金属）

**纹饰参考**：
- 核心纹样单独放大展示（花卉/缠枝/几何/符文）
- 标注使用位置

**锁定设定图**：
- 右下角放置一张完整角色渲染图，作为"最终效果锁定"

## 三、设定板通用规则

### 统一性规则（最重要）
- 所有视图的角色必须完全一致：脸型、五官特征、气质神态、发型、服装、配饰、比例
- 不允许出现"正面是A发型，背面是B发型"的错误
- 服装细节在各视图中对应（正面的腰带在背面也能看到带扣位置）
- 光影统一（设定板使用均匀漫射光，不使用戏剧性光影）

### 背景规则
- 设定板统一使用纯白/浅灰无缝背景
- 不使用场景背景、不使用道具
- 细金线/细灰线分区可选，增加专业感

### 光线规则
- 设定板使用均匀柔和正面漫射光
- 无硬阴影、无戏剧性明暗
- 目的是清晰展示服装与角色，而非营造氛围
- 单张概念图/海报可使用戏剧性光影

### 比例规则
- 用户指定比例时严格遵循（如九头身、腿长2/3）
- 未指定时使用写实自然比例
- 各视图比例必须一致

## 五、常见设定板类型速查

| 类型 | 视角数量 | 特写 | 拆解 | 色卡 | 适用场景 |
|------|---------|------|------|------|---------|
| 影视定妆照 | 3（正/侧/背） | 2（正/侧） | 无 | 无 | 影视剧角色定妆 |
| 游戏角色设定 | 6（含3/4） | 2+ | 面部+服装+武器 | 有 | 游戏原画/建模 |
| 服装展示板 | 3 | 1-2 | 面料+细节 | 可选 | 服装设计/电商 |
| 概念人设图 | 1（动态） | 无 | 无 | 无 | 概念艺术/海报 |
| 完整信息板 | 6+ | 4+ | 全拆解 | 有 | 顶级游戏/影视项目 |
