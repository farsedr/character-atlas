# 服装细节精细化描述与敏感词安全指南

## 一、服装描述五维拆解法

对任何服装，按以下五个维度逐层拆解，确保描述完整无遗漏：

### 维度1：款式结构（怎么穿）
- 领型：抹胸/心形领/深V/立领/翻领/一字肩/挂脖/斜肩
- 肩型：有肩带/无肩带/露肩/落肩/插肩/泡泡袖
- 袖型：长袖/七分袖/短袖/无袖/透纱袖/喇叭袖/羊腿袖
- 腰型：高腰/中腰/低腰/收腰/松紧腰/绑带腰/腰封
- 裙型：A字/鱼尾/蓬裙/包臀/直筒/不规则/高开叉/前短后长
- 裤型：直筒/阔腿/紧身/灯笼/束脚/开叉
- 闭合方式：拉链/纽扣/系带/绑带/套头/开衫
- 层数：单穿/叠穿/内搭+外衫+披帛三层结构

### 维度2：面料材质（什么质感）
- 缎面：光泽感、垂坠、顺滑
- 纱质：通透、轻盈、半透、飘逸
- 蕾丝：镂空、立体花卉、精致
- 粗麻/土布：粗糙织纹、做旧、磨损
- 牛仔：斜纹、硬挺、水洗褪色
- 针织：坑条、柔软、贴身
- 皮革：哑光/亮面、挺括
- 金属甲片：冷冽反光、雕花、铆钉
- 提花/暗纹：低调花纹、肌理感

### 维度3：装饰细节（有什么）
- 刺绣：花卉/缠枝/龙凤/几何/金线/银线
- 钉珠：珍珠/水钻/宝石/亮片
- 金属：雕花/护甲/链条/带扣/臂钏/胸针
- 飘带/披帛：材质、长度、垂坠方式
- 镶边：颜色、宽度、材质
- 褶皱：自然褶/工字褶/抽褶/荷叶边
- 做旧：磨损/褪色/污渍/补丁/毛边

### 维度4：身体呈现效果（穿上后）
- 上身：领口纵深线条、胸前曲线、肩颈裸露面积、锁骨呈现
- 腰部：腰线位置、收腰程度、腰腹镂空/裸露
- 下身：开叉高度、裙长位置、腿部裸露比例、臀型勾勒
- 整体：身形曲线流畅度、比例优化效果、露肤面积占比

### 维度5：最终视觉效果（整体调性）
- 性感程度：保守/适度/大胆/先锋
- 风格标签：清冷/仙气/魅惑/干练/质朴/华丽
- 反差感：例如"大胆露肤+仙气包装"、"性感剪裁+冷艳气质"
- 核心记忆点：最突出的1-2个设计特征

| | 舔/含/咬（身体部位） | 唇瓣微张、轻触、靠近（去掉动作对象） | 面部动作 |
| | 抚摸/爱抚/摸（身体） | 手部轻搭、指尖触碰、手置于（改为中性手部位置描述） | 手部动作 |

### 使用原则
1. **优先使用服装设计术语**：抹胸、深V、高开叉、露肩、镂空、腰封等都是安全的专业词汇
2. **用"效果"替代"部位"**：描述"领口纵深线条"而非"乳沟"，描述"腿部线条"而非"大腿"
3. **用"设计"替代"性感"**：描述"先锋剪裁"而非"大胆暴露"，描述"身形魅力"而非"性感"
4. **保留结构参数**：开叉高度（至胯部/至膝上）、领口形状（深心形/深V）、露肤位置（肩颈/腰腹）等具体设计参数必须保留
5. **最终效果用艺术化语言**："清冷中带魅惑"、"绝尘中藏身形魅力"、"仙气与剪裁张力并存"

## 三、常见大胆穿法的安全描述模板

### 模板A：低胸抹胸
```
无肩带抹胸式上装，领口呈深心形纵深线条，下缘位于胸下围提供承托，饱满上身曲线被结构托起，胸前形成自然纵深阴影与流畅轮廓，领口至锁骨区域完全裸露，皮肤在光下泛自然光泽
```

### 模板B：高开叉裙
```
高腰多层不规则裙装，前侧超高开叉从胯部起始，站姿时完全露出单侧腿部线条，开叉边缘胯部与腿部曲线自然过渡，内层衬裙短至膝、外层薄纱长至踝的多层结构形成若隐若现的动态效果
```

### 模板C：露肩露腰
```
完全露肩设计，双肩、锁骨、肩窝全部裸露无肩带遮挡；胸衣下缘与高腰裙头之间保留3-5cm腰腹镂空段，形成腰腹裸露效果，纤细腰线与平坦腰腹线条在光下呈现
```

### 模板D：透视材质
```
半透薄纱材质，纱质轻盈通透，内层衬裙提供基础包覆，外层薄纱在逆光下呈现发光质感，身体轮廓在纱层下若隐若现，形成朦胧的层次效果
```

### 模板E：包臀修身
```
高腰包臀剪裁，面料微弹贴身，从腰部至胯部至腿部的曲线流畅勾勒，裙长至大腿中部，下身轮廓清晰呈现，配合修身版型优化腰臀比例
```

## 四、服装描述质量检查清单

输出前逐项核对：
- [ ] 款式结构完整（领/肩/袖/腰/裙/闭合方式）
- [ ] 面料材质明确（至少1-2种核心面料及质感）
- [ ] 装饰细节具体（刺绣/钉珠/金属/飘带等）
- [ ] 身体呈现效果清晰（领口纵深、开叉高度、露肤位置）
- [ ] 最终视觉效果有调性（风格标签+反差感+记忆点）
- [ ] 无敏感词（对照映射表检查）
- [ ] 设计参数可量化（开叉至胯部、镂空3-5cm、裙长至膝等）

## 五、服饰部位精细化描述清单

描述服装时，必须按部位逐一覆盖，每个部位回答"什么款式+什么面料+什么装饰+穿在身上什么效果"：

### 上装部位清单
| 部位 | 必须描述的内容 |
|------|--------------|
| **领口** | 形状（心形/V/圆/方/一字/挂脖）、深度（到锁骨/到胸下围）、闭合方式、边缘装饰 |
| **肩部** | 有肩带/无肩带/露肩/落肩，肩带宽度材质，肩部是否有护甲/装饰 |
| **袖子** | 长度（无袖/短袖/七分/长袖）、袖型（直筒/喇叭/泡泡/羊腿/透纱）、袖口装饰、是否可拆卸 |
| **胸部** | 承托结构（抹胸/鱼骨/胸衣）、面料贴身程度、胸前装饰（刺绣/钉珠/宝石）、侧部结构（护甲/链条） |
| **腰部** | 腰封宽度材质、带扣样式、收腰程度、是否有镂空、镂空尺寸 |
| **背部** | 露背程度（全露/半露/绑带）、后背结构（绑带/拉链/刺绣）、肩带后背走向 |
| **衣摆** | 长度（到腰/到胯/到臀）、形状（平直/不规则/前短后长）、边缘装饰 |

### 下装部位清单
| 部位 | 必须描述的内容 |
|------|--------------|
| **裙头/腰头** | 高度（高腰/中腰/低腰）、宽度、装饰、与上衣衔接方式 |
| **裙型** | A字/鱼尾/蓬裙/包臀/直筒/不规则、蓬度、修身程度 |
| **开叉** | 位置（前/侧/后）、高度（到膝/到胯/到大腿根）、开叉边缘装饰 |
| **裙长** | 前片长度、后片长度、是否有拖尾、拖尾长度 |
| **裙层** | 层数、每层材质颜色长度、层叠方式、是否透视 |
| **裙摆** | 裙摆宽度、边缘装饰（镶边/刺绣/流苏）、是否有不规则剪裁 |
| **裤装** | 裤型（直筒/阔腿/紧身/灯笼/束脚）、裤长、裤脚设计、开叉位置 |

### 配饰部位清单
| 部位 | 必须描述的内容 |
|------|--------------|
| **头饰** | 位置（头顶/侧/额间）、材质（金属/珠宝/花/纱）、样式、是否有垂坠（流苏/步摇） |
| **耳饰** | 款式（耳钉/耳坠/耳圈）、材质、长度、是否有垂坠 |
| **颈饰** | 款式（choker/项链/璎珞）、材质、层数、吊坠样式、佩戴位置 |
| **手饰** | 手镯/手链/戒指、材质、佩戴哪只手、手指位置 |
| **臂饰** | 臂钏位置（上臂/前臂）、材质、是否垂链 |
| **腰饰** | 腰链/佩饰/挂环、材质、垂坠长度 |
| **腿饰** | 腿环/绑腿/袜装、位置、材质 |
| **鞋履** | 款式（高跟/平底/靴/凉鞋）、材质、颜色、鞋跟高度、装饰 |
| **武器/道具** | 名称、材质、尺寸、握持方式、是否有光效 |

## 六、姿态与身体语言精细化描述

姿态描述必须逐关节拆解，不可笼统写"站姿自然"。按以下部位逐一描述：

### 姿态拆解七部位

**1. 整体姿态与重心**
- 姿态类型：站姿/坐姿/蹲姿/跪姿/行走/动态
- 身体朝向：正面/侧身（多少度）/背面
- 重心：重心在左腿/右腿/双腿均匀/手/膝盖
- 身体倾斜：是否侧身、扭转角度、是否含胸/挺胸

**2. 头部**
- 头部角度：正视/微抬/低垂/侧倾（向左/向右多少度）
- 头部扭转：脸朝正前方/转向左侧/转向右侧（与身体朝向是否一致）
- 下巴：微抬/平齐/微收

**3. 眼神与表情**
- 视线方向：望向镜头/望向画面左侧/望向右侧/低垂/闭眼
- 眼神情绪：清冷/迷离/锐利/温柔/慵懒/坚定
- 表情：平静/微抿唇/微张唇/浅笑/冷峻（用安全表述，避免夸张）

**4. 肩部与躯干**
- 肩线：左肩高/右肩高/平行、肩部打开（展开胸腔）/含胸（内收）
- 肩颈角度：颈部挺直/微侧/前倾
- 躯干：挺直/微侧/扭转/前倾/后仰

**5. 手臂与手（最容易被忽略，必须详细）**
- 左臂：抬起角度（自然垂/抬至肩/抬至头/叉腰）、肘部弯曲度、前臂方向
- 左手：位置（身侧/胸前/头部/腰间/持物）、手指姿态（自然张开/微握/轻捏/轻抚）、是否持物
- 右臂：同上
- 右手：同上
- 双手互动：是否交叠/相握/一上一下

**6. 腰胯与骨盆**
- 胯部：是否侧顶（左顶/右顶）、骨盆扭转角度
- 腰部：是否扭转、前倾、侧弯
- 腰腹：是否收紧/放松

**7. 腿部与脚**
- 左腿：伸直/弯曲（多少度）、脚的位置（在前/在后/交叉/点地）、脚尖方向
- 右腿：同上
- 双膝：并拢/分开/一弯一直/交叉
- 双脚：并拢/分开（与肩同宽/更大）、一前一后（距离）、脚尖朝向（正前/外八/内八）、是否踮脚

### 姿态情绪对应参考
| 情绪/气质 | 姿态特征 |
|----------|---------|
| **清冷疏离** | 身体微侧，重心在一腿，另一腿放松，一手自然垂一手轻搭，头部微侧，眼神望向侧方或低垂，肩线放松不刻意 |
| **威严挺拔** | 正面站姿，双腿分开与肩同宽，重心均匀，双肩打开，躯干挺直，双手可背于身后或自然垂，头部正视，眼神坚定 |
| **慵懒魅惑** | 重心侧移一腿，胯部微顶，另一腿放松交叉，一手轻搭腰间或撩发，头部微倾，眼神望向镜头带迷离感，肩线一高一低 |
| **温柔娴静** | 正面或微侧，双腿并拢或一前一后，双手交叠置于腹前，头部微低，眼神柔和，肩线放松 |

### 姿态安全表述核心原则
1. **去场所化**：不写"跪在床上/趴在地上"，改为"低重心屈膝姿态/上半身伏于平面"，去掉具体场所的暗示性
2. **去动作化**：不写"扭动腰肢/撅臀"，改为"腰肢微转/侧身曲线"，用身体形态描述替代动作描述
3. **去方向化**：不写"从后方/背入"，改为"背面视角/回眸姿态"，用摄影视角替代动作方向
4. **用关节角度替代姿态名词**：不写"跪姿/深蹲"，改为"膝部弯曲呈低重心/髋部下沉"，用具体关节角度描述替代姿态标签
5. **用中性动词替代敏感动词**：不写"抚摸/爱抚"，改为"手部轻搭/指尖触碰/手置于"，去掉情感色彩
6. **保留姿态信息**：所有安全替换必须保留原始姿态的核心信息（重心位置、关节角度、身体朝向、手部位置），不可因安全而丢失姿态细节
