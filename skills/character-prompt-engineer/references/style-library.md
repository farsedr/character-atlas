# AI绘画风格描述库与选择指南

> 解决"出来全是二次元/3D/CG"的问题。核心原则：**默认使用真人摄影类风格，根据用户需求主动选择匹配风格，不默认CG渲染。**

---

## 一、风格选择决策树

输出提示词前，先判断使用哪类风格：

```
用户是否明确指定风格？
├── 是 → 严格使用用户指定的风格关键词
└── 否 → 判断图片/需求类型
    ├── 真实人像/街拍/写真/婚纱/商务 → 真人摄影类（默认）
    ├── 古风/仙侠/奇幻角色 → 真人摄影·奇幻写实 或 数字厚涂
    ├── 动漫/插画需求 → 动漫漫画类
    ├── 游戏角色/概念设定 → 写实概念设计 或 3D写实（仅用户要求时）
    └── 不确定 → 默认真人摄影·人像摄影
```

**⚠️ 重要：除非用户明确要求3D/CG/游戏风格，否则开头禁止写"CG渲染""3D渲染""游戏CG"等词。**

## 二、真人摄影类（默认首选，避免CG感）

### 2.1 真人摄影 / 人像摄影（最常用默认）
**关键词组合：**
```
真人摄影，专业人像摄影，真实皮肤纹理，自然毛孔与肌肤质感，真实光影，相机拍摄质感，浅景深虚化，8K超高清，照片级写实
```
**适用：** 所有人像类需求的默认风格，街拍、写真、婚纱、商务、日常

### 2.2 电影写实 / 电影摄影
**关键词组合：**
```
电影级写实人像，电影摄影机拍摄，宽银幕构图，电影色调（青橙色调/胶片色调），浅景深，电影级布光，真实皮肤质感，8K超高清
```
**适用：** 有故事感、氛围感的人像，影视定妆照，叙事性画面

### 2.3 商业棚拍 / 时尚摄影
**关键词组合：**
```
专业商业影棚拍摄，时尚大片质感，杂志封面摄影，专业影棚布光（柔光箱/雷达罩），纯色/渐变背景，高级时装摄影，真实皮肤质感，8K超高清
```
**适用：** 服装展示、商务肖像、时尚穿搭、产品人像

### 2.4 胶片复古
**关键词组合：**
```
胶片摄影，35mm胶片质感，胶片颗粒感，复古色调（暖黄/青绿色调），轻微漏光，柔焦，模拟胶片拍摄，真实皮肤纹理，8K超高清
```
**适用：** 复古风、怀旧感、文艺人像

### 2.5 照片级写实 / 极致写实
**关键词组合：**
```
照片级超写实，极致真实人像，每一寸肌肤纹理清晰可见，真实毛发丝缕，真实织物纹理，真实光影反射，超高清摄影，8K超高清
```
**适用：** 需要极致真实感的人像，超写实肖像

### 2.6 奇幻写实（古风/仙侠/奇幻角色首选）
**关键词组合：**
```
真人摄影·奇幻写实，真实人像摄影质感，真实皮肤纹理与织物细节，奇幻元素真实呈现，电影级布光，真实光影，8K超高清，照片级写实
```
**适用：** 古风汉服、仙侠奇幻、魔幻角色——保持真人真实感，不变成CG

### 2.7 唯美写实 / 梦幻摄影
**关键词组合：**
```
唯美写实人像摄影，柔和自然光，柔焦朦胧，暖金色调，散景光斑，梦幻氛围，真实皮肤质感，8K超高清
```
**适用：** 唯美、梦幻、仙气、柔美人像

### 2.8 艺术摄影
**关键词组合：**
```
艺术人像摄影，概念性艺术摄影，实验性光影，创意构图，艺术化表达，真实皮肤质感，8K超高清
```
**适用：** 艺术性、概念性、实验性人像

**关键词组合：**

中国水墨画风格，水墨晕染，留白意境，毛笔笔触，宣纸质感 / 工笔重彩，精细线描，矿物颜料色，传统国画质感，8K超高清

## 六、风格修饰词（可叠加在主风格后）

### 画质级修饰
- 8K超高清、4K超清、极致细节、超高分辨率
- 照片级写实、超写实、极致真实

### 镜头/摄影修饰
- 单反相机拍摄、50mm定焦镜头、85mm人像镜头
- 浅景深、背景虚化、焦外成像（bokeh）
- 微距摄影、广角、长焦压缩

### 胶片/质感修饰
- 胶片颗粒、柯达Portra 400、富士Provia
- 哈苏拍摄、徕卡拍摄
- 柔焦、锐化、高动态范围（HDR）

### 色调修饰
- 青橙色调（Teal and Orange）、电影色调
- 暖金色调、冷蓝色调、莫兰迪色调
- 低饱和度、高对比度、柔和对比

## 七、常见问题与修正

| 问题表现 | 原因 | 修正方案 |
|---------|------|---------|
| 出来像3D建模/CG | 开头写了"CG渲染""3D渲染""UE5渲染" | 改为"真人摄影""人像摄影""照片级写实" |
| 出来像二次元动漫 | 写了"动漫风格""插画"或风格词模糊 | 明确写"真人摄影""真实皮肤纹理""相机拍摄" |
| 皮肤太光滑像塑料 | 缺少真实皮肤描述 | 加"真实皮肤纹理、自然毛孔、肌肤质感、皮肤瑕疵" |
| 光影不真实像游戏 | 写了"游戏光影""CG光影" | 改为"真实光影、自然光照、电影级布光、影棚布光" |
| 古风角色像游戏CG | 写了"仙侠CG""3D古风" | 改为"真人摄影·奇幻写实、真实汉服质感、真实皮肤" |

## 八、标准开头行模板（按风格替换）

### 默认版（真人摄影，最常用）
```
8K超高清，真人摄影，专业人像摄影，真实皮肤纹理与自然毛孔，[角色类型][景别]，[画幅比例]，真实光影，[氛围关键词]
```

### 电影感版
```
8K超高清，电影级写实人像，电影摄影机拍摄，电影色调，浅景深虚化，[角色类型][景别]，[画幅比例]，电影级布光，[氛围关键词]
```

### 古风/奇幻版（推荐）
```
8K超高清，真人摄影·奇幻写实，真实皮肤纹理与织物细节，[角色类型][景别]，[画幅比例]，真实光影，[氛围关键词]
```

### 商业时尚版
```
8K超高清，商业时尚摄影，专业影棚布光，杂志大片质感，[角色类型][景别]，[画幅比例]，真实皮肤质感，[氛围关键词]
```

### ⚠️ 避免使用的开头（除非用户明确要求）
```
❌ 8K超高清，极致写实CG人像渲染...
❌ 8K超高清，UE5实时渲染...
❌ 8K超高清，3D超写实渲染...
❌ 8K超高清，游戏CG画质...
```
这些写法会强制模型走3D/CG渲染路径，导致人物像建模而非真人。
