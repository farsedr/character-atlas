## 十、使用建议

1. **正向提示词构建**：从衣服篇选服装 → 从姿势篇选姿态 → 从表情篇选表情 → 从背景篇选场景 → 从光线篇选光影 → 从风格篇定风格 → 从构图篇定构图
2. **反向提示词**：反向篇为基础必加项，根据具体画面补充针对性排除
3. **关键词组合原则**：每个维度选1-3个最精准的关键词，避免堆砌；关键词之间用逗号分隔
4. **优先级**：画质词 > 主体词 > 服装词 > 姿态词 > 场景词 > 光线词 > 风格词
5. **与技能配合**：本库用于快速检索补充，具体精细化描述仍需按SKILL.md的五维拆解法和五层光源体系展开
