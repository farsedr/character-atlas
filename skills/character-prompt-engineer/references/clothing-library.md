## 三、使用方法

1. **反推参考图时**：先判断风格大类（现代/东方古典），再定位子类，对照部位属性速查表逐项核对图片中的服饰元素
2. **从零设计时**：从常规款搭配示例中选取基础款，或从大胆款中选取风格方向，再按五维拆解法细化
3. **部位属性速查表**：用于快速检索某类风格下各部位的可选元素，确保描述专业准确
4. **搭配示例**：提供完整的场景+姿态+妆造+服装组合，可直接作为提示词骨架使用
