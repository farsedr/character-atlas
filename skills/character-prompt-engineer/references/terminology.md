# 可见特征术语参考
本文件仅供维护者查词，不自动加载，不是输出模板。只能采用当前图片有证据的词语。

- 服装结构：交领、立领、翻领、露肩、泡袖、宽袖、束腰、褶裥、开衩、披帛、叠穿；逐项指出可见部位与连接方式，遮挡处不补全。
- 材质外观：哑光、平滑光泽、织物纹理、半透明、皮革质感、金属反光、珠光；这些描述不等于确定化学成分。
- 光影：侧光、逆光、顶光、柔光、硬光、轮廓亮边、反射补光、背景散景；说明作用部位和证据，不指定精确色温与灯具参数。
- 姿态：站立、坐姿、俯身、转身、屈膝、抬手、持物；描述可见关节关系，左右不明时用画面左侧或右侧。
- 画风：摄影、插画、水彩、油画、动漫、三维渲染等仅凭可见表现判断；没有默认摄影、8K、软件或镜头型号。
- 空间：前景、中景、远景、遮挡、留白、对称、透视、景深；围绕当前图片组织，不生成三视图或新增背景。

表达顺序可采用“主体与画风—可见结构—姿态—空间—光色”，也可按画面重点调整。无需填满每个类别，不添加反向提示词套话。
