# 拾光图鉴通用本机连接包

安装 Node.js 22+；安装并登录 Codex CLI 或 Gemini CLI。

Codex: npm install -g @openai/codex，然后 codex login。
Gemini: npm install -g @google/gemini-cli，然后 gemini，选择 Login with Google。

完整解压，Windows 运行 start-codex.cmd；macOS/Linux 运行 sh start.sh。
打开 http://127.0.0.1:4379/，将连接码粘贴到网站模型设置。

安装位置自动寻找。包内无账号、API密钥或配对码。每次启动生成新配对码。
指南：https://character-atlas-wang-20261003.wqlwoaiwo.chatgpt.site/connection-guide.html
