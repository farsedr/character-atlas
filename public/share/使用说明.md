# 拾光图鉴使用说明

对应2026-10-17更新后的网页版。网站与桌面本地库独立；旧安装包不会自动获得网页更新。

## 登录与账号

注册后保存恢复代码。邮箱目前仅作登录名，不支持邮件找回；恢复密码后旧代码与旧会话失效。“账号安全”可修改密码、管理会话。

素材、标签、灵感集、模型配置按账号隔离；网页版同一账号跨设备访问云端数据。安装网页应用仍需联网，不是离线素材库。

## 上传与任务

支持多选图片、重复添加图片和选择文件夹；支持PNG/JPEG/WebP，单张最大20MB、最多6400万像素，其他格式跳过。原图原始字节保存，预览另存。原文件名在后台保留用于搜索，不作为详情中的一项展示。

默认模型命名与模型分组，也可保留原文件名、手动命名并指定多个灵感集。自动命名和分组仅在实际执行模型分析后产生。取消自动分析或直接保存时，按已填写信息入库，不调用模型。

“开始处理”按设置上传和分析；“保存”才正式入库。分析失败不丢失已上传原图，可重试或保存现有内容。单张取消只清理该张，仍可添加其他图片；整批取消只清理未保存数据。

默认同时分析3张，可选1至5张，实际并发受本机连接包支持能力限制。失败立即显示原因，不自动重试、不自动升级模型；限流可降低并发后手动重试失败项。

收起任务窗口后当前页面继续处理。关闭全部网页会中断页面调度；已上传草稿在下次登录恢复，可在“后台任务”继续未完成项。尚未上传的本地文件可能需要重选。

## 主图与集合

从主页面打开“上传素材”，可在“保存方式”选择“独立素材”或“组成集合”。默认独立素材，保持原有逐张入库方式；选择组成集合后，本批图片只创建一个集合。

选图后默认第一张为主图，可点击其他缩略图“设为主图”，上传和分析完成后、保存前仍可更换。保存时以主图的灵感集为准，各图保留自己的名称，子图的标签、描述、提示词保留独立分析结果。只有主图进入灵感总览、占一个编号，集合草稿和子图均不占编号。

“保存集合”统一保存本批已上传成功的图片。主图没有上传成功或已取消时，需重新选择；单张分析失败仍可保存其已上传原图，之后重试分析。未上传成功的文件留在任务中可重试。集合创建后继续添加的图片作为子图；更换主图使用素材详情的“设为主页”。已开始上传后不能切换保存方式，应完成或取消本批再新建任务。重复保存不会重复创建集合。

“集合 → 上传”只向当前主图的集合添加图片，不另外进入灵感总览、不占独立编号。各图名称独立，灵感集跟随主图，其余标签、描述、提示词独立分析。草稿需点击保存。

图片下方“选择”用于多选，“删除”只删除对应图片。集合工具栏提供保存选中、下载选中、删除选中、仅重试失败项；“全选”是点击变色的文字按钮。

选中已保存的集合图片后显示“设为主页”。切换后沿用原主图编号，原图保留在集合。单独删除主图且集合有剩余图片时，先选已保存图片接替。整组与单张删除的范围以确认窗口为准。

放大只显示图片；滚轮缩放整个图像，放大后可拖动。点击空白或按Esc返回，松开鼠标不关闭。

## 批量编辑

灵感总览多选后点击“批量编辑”，每批最多50张，范围为当前页选中的已保存主素材。

- 添加/移除标签：按父类别和标签名匹配，保留其他标签；添加的同名标签按手动标签保存。
- 追加灵感集：保留原归属并追加。
- 替换灵感集：用所选归属替换原归属；灵感集变更同步到其集合图片。
- 重新分析：先勾选允许应用的字段，默认仅标签；确认后逐张执行，锁定字段和手动标签保留，每张显示成功或失败。停止会在当前图片完成后停止后续项，已完成结果保留。

普通批量编辑遇到版本冲突，本批不修改，请刷新重选。批量分析逐张保存，可能部分成功，失败不自动重试。

## 分析对比与字段锁定

已保存素材的“分析标签”先展示当前内容与模型建议，不直接覆盖；勾选字段后点击“应用选中字段”。取消保留原内容。在编辑页分析时先保存当前填写内容，再对比模型结果。

“编辑 → 分析字段锁定”支持名称、灵感集、标签、描述、提示词。保存后由服务端保护：自动分析、对比应用、批量分析均不能覆盖锁定字段，仍可手动编辑。集合灵感集始终跟随主图，各图名称独立；手动命名、手动分组仍保留，不因分析自动切换管理方式。

新上传草稿按任务设置分析，不逐张弹出对比。普通主图自动分析保留手动标签及已填写描述、提示词。集合自动分析沿用原有独立分析规则，需要保留的字段可先锁定；对比中明确勾选描述或提示词时，可替换未锁定内容。

默认执行24维视觉分析，详情展示12个父标签。模型返回先兼容规范化再校验；不可修复的缺失/错误会报错，不伪造结果。自定义分析规则在模型设置安装，固定输出契约和视觉依据要求仍生效。

## 相似图片

详情点击“查找相似”。结合相同原图、图像特征和共有标签推荐候选，不代表相同人物、作者或作品，不自动归组。当前搜索当前账号最近5000张已保存图片，包含集合；页面显示范围与索引覆盖。

新上传尽可能生成图像特征；旧图点击“为已有素材建立索引”，逐张处理预览，不调用付费模型。可中途停止，下次处理未索引项；预览读取失败记为失败。

点击候选双图对比，查看标签、描述和尺寸，并可放大。“复制加入集合”保留候选原素材及编号，复制独立文件到当前主图集合；副本不占编号、名称独立、灵感集跟随主图。裁剪、构图变化、纯色图片可能影响准确度，需人工确认。

## 存储信息

左侧“存储信息”按主素材、集合、草稿、回收站显示数量、原图和已记录预览大小。旧图缺少预览大小时标注待检查。不含数据库、历史无关联孤立文件或其他账号，也不代表平台存储配额。

开始检查会按批读取关联文件，统计可读取大小，检查原图/预览丢失、集合关联异常、超过7天的草稿、超时未结束的分析。可中止；期间发生上传/删除时，以重新检查为准。

检查不自动删除。可“查看素材”“处理草稿与失败任务”“打开回收站”；原图存在而预览丢失时可“重建预览”。丢失原图不能从预览恢复原始质量，应从备份重新上传；集合关联异常需人工确认归属。

## 搜索、灵感集与下载

支持素材名、后台原文件名、描述、标签、提示词和编号搜索，以及12父类别、灵感集筛选。每页按屏幕列数显示四行，可输入页码跳转。

系统保留10个灵感集：东方古风、仙侠幻想、西方奇幻、科幻未来、现代人物、动漫角色、角色设定、自然风景、建筑空间、器物设计。模型优先复用合适分类，一图可归属多个。普通灵感集支持改名、合并、删除空集；有草稿/回收站关联不算空集，不因数量为零自动删除。系统灵感集不可改名、合并或删除。

原图及ZIP使用当前素材名，同名加序号，不重新压缩原图。每个ZIP最多200张，更多分包。ZIP仅下载图片，不是含标签和集合关系的完整素材库备份。

## 删除与网盘备份

删除先进入回收站，可恢复；永久删除需确认，不可恢复。回收站仍占空间。显示编号可重用，内部标识不重用；集合不占编号。CHAR-00001至CHAR-99999是主素材编号范围，不是容量承诺。

百度网盘需管理员先配置正式获批应用；普通用户在“云盘连接”授权本人账号、检测连接并启动备份。文件在普通网盘apps应用目录，记录显示具体路径。关闭全部页面后未完成队列在下次登录继续。

移入回收站不删除网盘备份。永久删除确认可另选“同时删除百度网盘备份”，默认不勾选；网盘删除失败时保留网站文件以便重试。网盘原图备份不包含完整标签与集合数据库。

## 模型连接

本机Codex/Gemini：自行安装Node.js 22+与相应CLI，用本人账号登录；解压通用连接包，Windows运行start-local-models.cmd，Mac/Linux执行sh start.sh。复制http://127.0.0.1:4379/的连接码，在模型设置配对并允许本地网络访问。连接包保持运行，重启重新配对；手机不能直接连接另一台电脑的localhost。

也可配置自己的视觉API：选择服务商、支持图片的模型ID、HTTPS基础地址、密钥及协议。支持OpenAI兼容Chat、Responses、Anthropic、Gemini原生协议。可用模型、地区、额度和价格以服务商官方后台为准，不承诺免费额度。失败不自动调用其他付费配置，不要分享密钥或配对码。

详细步骤：网站/connection-guide.html；百度管理员配置：docs/BAIDU-GUIDE.md。

## 桌面与开发

Windows桌面本地账号与网站账号独立，SQLite与原图目录不自动同步云端。旧安装包需重新构建安装才有新功能；Alt打开备份/恢复菜单，详见docs/DESKTOP-GUIDE.md。

开发使用Node.js 24+：npm ci、npm run build、npm test、npm run preview。本地预览为临时数据，与生产隔离。生产使用DB/D1与BUCKET/R2，按文件顺序应用drizzle/全部SQL迁移，不依赖写死迁移数量。AI_CONFIG_KEY是部署秘密，不得提交或随意轮换。

## 图片加载与同步优化

新上传图片自动生成列表缩略图和详情预览，原图不压缩；旧素材继续使用已有预览，无需重新上传。集合缩略图按需加载，完整分析与提示词在打开详情时获取。

预览使用浏览器私有缓存，每次复用先校验登录权限和图片版本；图片更新后重新获取，退出账号时请求浏览器清理缓存。此功能不等于离线图库，也不提供跨设备缓存同步。

后台刷新时资料未变化则保持当前列表，不重建卡片。翻页复用近期的标签、配置和项目统计；手动刷新或本机修改后重新读取，其他设备的辅助资料变更通常在后续自动刷新中更新。

百度备份单张失败不阻塞其他等待项；短暂连接中断后逐步重试，任务被其他设备暂时占用时稍后继续。暂停本页后不会自动恢复，失败项仍通过重试按钮处理。关闭全部页面后不保证持续执行，下次登录可继续。

## 内置分析规则 1.1

API 与新版本机连接包共用24维输出契约。画面按人物、风景建筑、产品器物或混合主体分别观察；子标签开放生成，每项辅助标签须有具体证据。不适用与未知分开处理，不猜真实身份或摄影参数。

集合只继承灵感集，每张素材独立命名，其余特征独立分析。模型输出是提案，字段锁与选择性应用由程序执行；历史创作模板不参与运行时分析。格式兼容只转换缺失的空辅助数组、明确的数字/布尔字符串等，不补造缺失维度或视觉结论。

网站API规则随发布更新。本机Codex/Gemini需要重新下载连接包、解压并重启；已启动的旧连接包不会自动换用新规则。
