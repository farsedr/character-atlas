下载完整教程百度官方开放平台

1. 管理员申请

  1. 在百度网盘开放平台完成开发者入驻、实名认证并创建应用。正式接入资格以当前平台审核要求为准。
  2. 申请私有素材备份所需的上传、查询、下载、账户信息和容量权限；确认允许的应用目录、费用和调用频率。
  3. 用途填写：用户通过官方授权，将自己的原图备份至本人网盘，不提供公共图床或共享账户。
  4. 登记回调地址：https://character-atlas-wang-20261003.wqlwoaiwo.chatgpt.site/api/storage/baidu/callback

2. 配置网站

由管理员通过安全的运行环境配置 Client ID、Client Secret、正式网站地址及获准的应用目录，然后重新发布。保留现有加密密钥，不要把密钥上传 GitHub 或发到聊天中。完整变量清单见下载教程。

3. 用户连接

  1. 登录拾光图鉴，点击左侧“云盘连接”。
  2. 点击“连接百度网盘”，跳转百度登录并授权。
  3. 返回后检测连接，打开自动备份；历史素材可点击“备份现有素材”。
  4. 在其他设备登录同一拾光图鉴账号，无需重新配对本机程序。等待任务可继续备份，完成后可下载备份。

跨设备、进度与删除

授权和分片进度保存在服务端，授权到期前自动刷新。撤销授权后需重新连接。所有页面关闭后，尚未完成的任务会保留，下次登录继续；本版本没有全天候离线任务调度。

标签、提示词、多个灵感集关联和缩略图保留在网站。网盘按内部素材 ID 存储，从网站下载仍使用素材名。

网站回收站与断开连接不删除百度中的备份文件。断开会清除网站连接及备份记录；需要撤销百度授权时，到百度账号授权管理中解除关联。
