LOCAL CONNECTION

连接本机 Codex / Gemini

每位用户使用自己的登录账号与额度。连接包不包含任何账号、密码、API 密钥或配对码。电脑需保持连接程序运行。

1. 安装运行环境

安装 Node.js 22 或更新版本，完成后重新打开终端。已安装 Codex 桌面版的电脑可自动寻找其附带环境；找不到时仍需安装 Node.js。

2. 安装并登录 CLI

本机 Codex

npm install -g @openai/codex
codex login

在浏览器中使用自己的 ChatGPT 账号登录。默认 GPT-6 Luna、低推理强度。可用模型与额度以账号为准。

本机 Gemini

npm install -g @google/gemini-cli
gemini

首次启动选择 Login with Google，完成个人 Google 账号登录后退出 CLI。然后启动同一个通用连接包，在网站模型设置将「本机来源」改为「本机 Gemini」，粘贴连接码并点击连接，选择有权限的 Gemini 视觉模型；下面 API 配置无需填写。公司或学校账号可能需额外项目设置。查看官方登录说明。默认 Gemini 2.5 Flash Lite；未授权的模型会提示错误，请自行选择可用模型。

3. 下载并启动连接包

下载通用连接包（含 Codex / Gemini）

先完整解压。Windows 双击 start-local-models.cmd（也可使用 start-codex.cmd 或 start-gemini.cmd）；macOS / Linux 在解压目录运行 sh start.sh。程序自动寻找安装位置，不要求固定用户名或目录。启动后打开 本机连接页。

4. 配对与状态检测

复制本机页面的连接码，回到拾光图鉴的「模型设置」，粘贴并点击「连接」。允许浏览器访问本地网络。选择「本机 Codex」或「本机 Gemini」，查看安装和登录检测状态，再选择模型。每次重启连接程序都需要重新配对；配对码仅保存在本次页面会话中。

Gemini 的登录检测检查本机登录缓存，不代表当前网络和账号授权一定正常。模型不可用、登录失效或额度不足时会停止分析并提示，不自动升级到更贵模型。分析时可再次单独选择模型。

5. 安装分析 Skill

在「模型设置 → 分析 Skill」下载模板，修改后选择 SKILL.md 并点击「安装 Skill」。每个账号独立保存，也可以恢复内置规则。Skill 只补充分析指令；固定父类别、证据要求和输出格式继续生效。子标签由模型根据图片生成。

6. 自动分组与下载

分析后自动分组灵感集，优先复用已有集合。手动指定的分组会保留。原图与批量 ZIP 使用当前素材名。

连接不成功时

确认 CLI 已安装并登录，连接程序仍在运行，浏览器允许访问本地网络，连接码来自本次启动。如果旧版程序占用 4379 端口，请关闭旧连接程序再启动新版。未登录时先打开终端完成账号登录。换设备需要在新设备重新安装与配对。
