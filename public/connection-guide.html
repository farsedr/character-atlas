第一次使用，跟着做就能连接

模型连接负责分析图片；网盘连接负责备份原图。两项可以分别设置。已经完成的步骤可以跳过。

连接百度网盘：只需三步

  1. 返回网站，点击左下角“☁ 云盘连接”，再点“连接百度网盘”。
  2. 在百度页面登录自己的账号并授权。返回网站后点“检测连接”，出现容量说明连接正常。
  3. 勾选“以后新上传的素材自动备份”，或点击“备份现有素材”。记录显示完成后，可以点击“下载备份”。

换手机或电脑时，登录同一个拾光图鉴账号即可继续使用，不用重复填写密钥。百度撤销授权后需要重新连接。

到百度网盘查看时，请打开普通网盘“全部文件 → apps → 应用目录”，不要进入“同步空间”。网站备份记录会显示具体路径。文件使用唯一编号命名，下载备份时会恢复为素材名。

普通用户不用申请百度开放平台应用。管理员申请与配置说明仅供自建网站使用。

连接模型：选择 Codex 或 Gemini

在网站“✧ 模型设置”中选择自己要用的工具。本机 Codex 用 ChatGPT 账号，本机 Gemini 用 Google 账号；两者都不要求填写 API 密钥。账号可用额度以服务商为准。

1. 安装工具（已安装可跳过）

先安装 Node.js 22 或更新版本，使用安装程序的默认选项。安装完成后重新打开终端。

Windows：右键点击桌面底部的开始菜单，打开“终端”或“PowerShell”。Mac：打开“启动台 → 其他 → 终端”。命令一次粘贴一条，每条按 Enter 执行。网站模型设置里提供“复制命令”按钮。

我使用 Codex
npm install -g @openai/codex
codex login

按照提示用自己的 ChatGPT 账号登录。Codex 官方安装说明

我使用 Gemini
npm install -g @google/gemini-cli
gemini

出现登录方式时选择 Login with Google，完成登录后退出 Gemini。公司或学校账号可能需要额外设置，按官方说明操作。Gemini 官方登录说明

2. 下载连接包，解压后启动

下载通用连接包（Codex / Gemini）

不要直接在压缩包内运行。先右键压缩包，选择“全部解压”。Windows 在解压目录双击 start-local-models.cmd，保持打开的窗口运行；Mac / Linux 在解压目录打开终端并执行 sh start.sh。

3. 复制连接码，返回网站连接

打开 本机连接码页面，复制连接码。回到网站模型设置，粘贴到连接码输入框，点击“连接并检测”。若浏览器询问是否允许访问本地网络，请允许。

4. 检查登录状态，开始分析

页面提示已连接并检测到登录后，在上传素材时勾选自动分析即可。默认使用轻量模型，也可以展开“调整模型与推理强度”自行选择。不分析时，取消上传界面的自动分析勾选。

本机连接需要这台电脑上的连接包保持运行。换电脑需重新安装和配对；手机上的网盘功能仍可使用，但手机不能直接运行这个电脑连接包。

有 API 密钥，想用服务商接口

在模型设置展开“使用 API 密钥连接”：选择服务商，复制支持图片分析的模型名称和 API 密钥，点击保存。服务地址和接口格式通常保持默认；自定义服务商按其官方文档填写。保存的配置随网站账号同步，调用费用由所选服务商收取。

想安装自己的分析规则 Skill

展开模型设置中的“自定义分析规则 Skill”，下载模板并编辑，选择自己的 SKILL.md 文件，再点击安装。没有自定义规则时直接使用内置规则即可。

卡住了？按提示检查

  • 提示找不到 npm：安装 Node.js 后关闭旧终端，再打开新终端。
  • 本机页面打不开：确认解压后已启动连接包，窗口保持打开。旧包占用 4379 端口时关闭旧连接包，再启动新版。
  • 连接包已配对但未登录：完成对应 Codex / Gemini 的账号登录，再连接。
  • 连接码不正确：从当前运行的连接包页面重新复制。重启后连接码会改变。
  • 模型没有权限或额度不足：选择账号可用的模型，或检查服务商额度。程序不会自动换成更贵的模型。
  • 百度显示等待平台配置：请联系网站管理员，普通用户无需自行填写密钥。
  • 网盘备份失败：检查剩余空间，点击重试失败；必要时重新备份该条记录。
